# Documentation Screenshot Checklist

Use screenshots from the final locally verified build for the project report/presentation. Do not place secrets, API keys or private user data in screenshots.

Recommended screenshots:

1. Login / registration page.
2. Main dashboard with nutrition summary.
3. Profile page showing goals, diet and allergy settings.
4. Meal diary with a logged meal and nutrition totals.
5. Personalized meal-plan screen.
6. AI Nutrition Advisor in English.
7. AI Nutrition Advisor in Amharic.
8. Food photo scanner result.
9. Allergy/diet conflict warning or blocked food result.
10. Progress/analytics page.
11. Mobile-width dashboard.
12. Mobile-width advisor or scanner.
13. Admin page, if included in the final demonstration.

## Screenshot rules

- Use test/demo accounts only.
- Never show `.env`, passwords, JWT secrets, Gemini API keys or real personal information.
- Prefer browser screenshots at consistent dimensions.
- Capture both desktop and narrow mobile layouts for responsive evidence.
